# Rebodocs 是什么

Rebodocs 是一款运行在浏览器中的文字处理器，兼容 Word 文件（DOCX），拥有自己的引擎。文档模型、断行、分页、光标、选区以及 DOCX 的读写都是从零编写的。它不使用 ProseMirror、`contenteditable` 或任何编辑库。

它的设计初衷是嵌入另一个应用：一个用合同和收据模板生成文档、并允许用户编辑结果的 CRM。因此它以软件包的形式提供，你可以按需逐个选用。

## 你能得到什么 {#what-you-get}

- **一个文字处理器。** 格式、样式、列表、制表位、表格（支持单元格内嵌表格和竖排文字）、分栏、带独立页面设置的分节、图片、文本框、页眉页脚、脚注、页码、链接、批注、目录、查找和替换。
- **修订**，与 Word 一样：输入和删除的内容会一直标记，直到有人接受或拒绝。
- **版本**由你的应用保存，可以逐词对比并还原。
- **与 Word 兼容。** 它读写 DOCX，并按相同的规则断行和分页，因此文档在两者中看起来一样。
- **文件完好无损。** 编辑器不理解的内容会原封不动地保留在 DOCX 中。
- **模板。** 任何文档中的 `{{客户}}` 都是待填写的变量；输入 `{{` 即可列出你的应用会填写的变量。
- **待填区域。** 可以把文档限制为只能编辑待填区域，其余部分只读，在 Word 中同样有效。
- **“/” 命令**：标题、列表、表格、图片、签名，以及你自己的命令。
- **在服务器上生成 PDF 和 DOCX**，排版完全一致，不需要浏览器。
- **实时协作**，由你的后端保存文件，还可以为每次工作会话保留一个版本。
- **中文及其他语言。** 中文按字符断行，遵守避头尾规则（行首不出现“。”“，”），界面支持中文、英文和西班牙文。
- **适配手机的编辑器**：适应宽度、双指缩放、触控选择。

## 软件包 {#the-packages}

| 软件包 | 何时选用 |
| --- | --- |
| `@rebodocs/react` | 你有一个 React 或 Next.js 应用，想在某个页面中放入编辑器。 |
| `@rebodocs/editor` | 你想在不使用框架的页面中放入编辑器，或基于它的部件进行构建。 |
| `@rebodocs/viewer` | 你只需要展示文档：可阅读的页面、缩略图，不需要编辑。 |
| `@rebodocs/core` | 你要用代码生成或转换文档：填写模板、生成 PDF。 |
| `@rebodocs/collab` | 多人需要同时编辑同一份文档。 |
| `@rebodocs/mcp` | 需要让 AI 助手读取和编辑文档：Claude Desktop 及其他 MCP 客户端，或你应用中的 Claude 聊天。 |

[软件包](/zh/docs/packages/)一页介绍了每个软件包包含什么，以及它们之间的依赖关系。

## 它不是什么 {#what-it-is-not}

- **不是 Word 的复制品。** Rebodocs 不是 Microsoft Word 的复制品，也无意成为它。它是一个独立的文字处理器，兼容 DOCX 格式：能打开 Word 保存的文件，Word 也能打开它保存的文件，而且两者中的页面完全一致。它没有 Word 的全部功能，但有一些自己独有的功能，比如模板变量。它新增的一切在保存时都会确保 Word 能打开并正确显示。

- **不是托管服务。** 没有任何需要注册的东西。它是由你自己运行的代码。
- **尚未完成。** 它经过了测试并已发布到 npm，但还不能做所有事情。[现状与路线图](/zh/docs/status/)坦率地列出了哪些已验证、哪些还缺。
